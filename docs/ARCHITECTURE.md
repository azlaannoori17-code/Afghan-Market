# Afghan Market — System Architecture

## 1. Project Overview

Afghan Market is a nationwide multi-vendor e-commerce platform designed for Afghanistan.

The platform connects customers, independent sellers, and Afghan Market's own store.

## 2. Main Business Modules

### Afghan Market Store
Products owned and sold directly by Afghan Market.

### Multi-Vendor Marketplace
Independent sellers can register, create stores, and sell products.

### Sales Commission
Commissions are calculated from real, completed product sales.

## 3. Planned Technology Stack

- Frontend: Next.js
- Backend: NestJS
- Database: PostgreSQL
- ORM: Prisma
- Cache: Redis
- API: REST
- Package Manager: pnpm

## 4. Core Platform Features

- Customer accounts
- Seller registration and management
- Product catalog
- Categories and brands
- Search and filters
- Shopping cart
- Order management
- Inventory management
- Payment management
- Delivery management
- Admin dashboard
- Financial reporting
- Authentication and authorization

## 5. Security Principles

- Secure password handling
- Role-based access control
- Input validation
- Protected API endpoints
- Environment-based secrets
- Secure database access

## 6. Development Strategy

The platform will be developed in stages.

1. Project foundation
2. Customer and seller accounts
3. Product management
4. Shopping cart and orders
5. Payments and delivery
6. Administration and reporting
7. Testing and deployment
