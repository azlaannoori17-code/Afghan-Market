# QAVENTRIX

### Global Multi-Vendor E-Commerce Marketplace

QAVENTRIX is a global-ready multi-vendor e-commerce marketplace designed to connect customers, independent sellers, and businesses through one unified digital commerce platform.

The platform will initially launch in Afghanistan, with a long-term vision of expanding into international markets.

## Our Vision

To build a trusted, scalable, secure, and innovative global marketplace that connects customers and sellers through a reliable digital commerce ecosystem.

## Getting Started

### Prerequisites

Before starting development, make sure you have installed:

- Node.js
- pnpm 10 or a compatible version

### Installation

Clone the repository:

    git clone https://github.com/azlaannoori17-code/QAVENTRIX.git

Navigate to the project directory:

    cd QAVENTRIX

Install dependencies:

    pnpm install

Start the development server:

    pnpm dev

The web application will run using the Next.js development server.

## Development Commands

Run the development server:

    pnpm dev

Build the application:

    pnpm build

Run lint checks:

    pnpm lint

Run TypeScript checks:

    pnpm typecheck
